# Front Desk Frenzy 🎄🛎️

A Christmas browser game made for Lisa and Mitra at the Belmont Village front desk, with love from Mag, Tony, Samantha and George.

**Play:** https://georgeconstablecreative.github.io/Front-Desk-Frenzy/

Designed for iPhone: open the link in Safari, then Share → **Add to Home Screen** to keep it like an app.

## What's inside
- **The story:** three shifts (morning, noon and evening), eight guests each, with an arcade break between shifts and a Christmas card from Mag and Tony at the end
- **The Arcade:** Snowball Volley, Fruitcake Catapult, Roomba Invaders and Jingle Bell Jam

## Files
- `index.html`: the whole game in one file (no build step needed)
- `front-desk-frenzy-christmas-qr.png`: printable Christmas card with a QR code (app icon in the centre) that opens the game (print about 4×6 in)
- `front-desk-frenzy-qr-plain.png`: plain black-and-white QR code, the safest to scan when printed small
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-1024.png`: the Christmas app icon (a front-desk bell in a Santa hat) used when it's saved to the Home Screen
- `manifest.webmanifest`: app name and icons for Add to Home Screen
- `.nojekyll`: tells GitHub Pages to serve the files as they are
